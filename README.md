## 📌 Sobre este repositório

Este repositório reúne todos os projetos desenvolvidos durante duas trilhas práticas de estudo criadas para acelerar meu aprendizado em programação e desenvolvimento web.

As trilhas foram organizadas com foco em **aprendizado ativo**, resolução de problemas reais, construção de portfólio e desenvolvimento progressivo de habilidades técnicas.

O objetivo não é apenas estudar teoria, mas **transformar conhecimento em projetos concretos**, simulando desafios encontrados no mercado de tecnologia.

---

## 🛠 Trilhas de estudo

### 📜 DesafioJS

Trilha focada em desenvolvimento da lógica de programação utilizando JavaScript.

Aqui são desenvolvidos algoritmos e pequenos sistemas para praticar pensamento computacional e resolução de problemas.

Exemplos de projetos:

- Contador de vogais
- Sistema de cálculo de médias
- Busca de alunos
- Sistema de aprovação
- Filtros em arrays
- Manipulação de objetos
- Algoritmos matemáticos
- Funções e estruturas de repetição

---

### 🎨 DesafioHTMLCSS

Trilha focada em desenvolvimento Front-End utilizando HTML e CSS.

O objetivo é construir interfaces progressivamente mais profissionais, aplicando boas práticas modernas de estruturação e estilização.

Exemplos de projetos:

- Landing pages
- Formulários
- Tabelas HTML
- Páginas responsivas
- Layouts com Flexbox
- Layouts com Grid
- Estrutura semântica
- Componentes visuais
- Animações e transições

---
